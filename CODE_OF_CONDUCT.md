# Code of Conduct

## Our standard

Everyone participating in this project — issues, pull requests, discussions —
is expected to be respectful and constructive.

Not acceptable: personal attacks, harassment, discriminatory language, and
publishing others' private information (including camera footage, addresses,
IP addresses, or credentials that appear in someone's logs).

That last point matters more here than in most projects: this repository deals
with cameras pointed at real homes and workplaces. Treat any footage, address
or credential that turns up in a bug report as private, and say so rather than
quoting it.

## Scope

Applies in all project spaces and when representing the project publicly.

## Reporting

Report unacceptable behaviour through
[Reolink support](https://support.reolink.com), noting that it concerns the
`reolink-cli` repository. Reports are handled confidentially. Maintainers may
edit, remove, or reject contributions that violate this document, and may block
repeat offenders.
