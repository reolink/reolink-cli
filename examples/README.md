# Examples

Automations people built on top of `reolink-cli` and sent back. Each directory
is one recipe with its own README: what it does, what it was run against, and
what it printed.

Read one before you run it. Nothing here is fetched by the installer, executed
by the CLI, or covered by the compatibility promise the CLI itself makes —
these are contributed and contributor-maintained.

**The built-in starters are not here.** `reolink-cli events monitor init`
writes a commented rules file covering person snapshot, vehicle logging,
spotlight blink, PTZ-to-preset and the `exec` escape hatch. Start there; this
directory is for what you built afterwards.

To add one — and to check whether yours is a recipe at all, or a missing
command we should just build — see
[CONTRIBUTING.md](../CONTRIBUTING.md#automation-recipes).
